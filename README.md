## 📱 Como usar o Quiz

1. **Abra o quiz** no link acima
2. **Escolha o modo:**
   - **Múltipla Escolha** - 40 questões com explicação
   - **Cards** - 18 cards de memorização de conceitos
3. **Selecione a matéria** (Java, Python, SQL, AWS, Arquitetura ou Todas)
4. **Defina** quantidade de questões e cronômetro
5. **Veja seu histórico** de evolução
